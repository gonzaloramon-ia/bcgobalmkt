# BillCounter Global — interface prototype

Static first-pass interface for the global cash-handling equipment network.

## Direction

- Discovery and qualified inquiries first; no payment or marketplace transaction yet.
- Three entry points: solutions, markets and supplier partnerships.
- Buyer request form captures market and need before a future routing layer is added.
- The visual system uses a technical B2B tone distinct from Bill Counter Argentina.
