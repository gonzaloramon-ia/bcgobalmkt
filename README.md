# BillCounter Global Marketplace

Production-ready static MVP for an international cash-handling marketplace.

## Current capabilities

- Equipment catalogue and category pages
- Market routes and worldwide discovery
- Equipment detail pages
- Local saved-equipment shortlist
- Buyer inquiries routed by email
- Supplier application through the official Google Form
- Light and dark themes
- Responsive navigation and accessible controls
- SEO metadata, sitemap, robots file and structured data
- Marketplace, privacy and terms information

No payment is processed on this website. Buyers and sellers arrange payment and delivery directly.

See `ARCHITECTURE.md` for the future database-backed phase.
